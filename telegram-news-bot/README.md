# FLUX WIRE — новостной Telegram-канал на автопилоте

Бот каждые 10 минут собирает свежие новости из зарубежных изданий, отбирает только важное,
переводит на русский и публикует в канал. Вечером в 21:00 выходит дайджест дня.

## Как выглядит пост

```
[крупная картинка из статьи или видео, если оно там есть]
🤖 Понятный заголовок: сразу ясно, о ком и о чём речь

Краткий пересказ: что случилось, в двух предложениях.

▪️ ключевой факт (цифры, сроки)

❓ Что это значит?
Простыми словами: что эта новость меняет и почему она важна.

The Verge · MIT Technology Review  #ии
[📖 Читать полностью]
[🔗 The Verge] [🔗 MIT Technology Review]
```

- **📖 Читать полностью** открывает полный перевод статьи прямо в Telegram (Telegraph).
  Видео из статьи (YouTube, Vimeo) встроены туда же, их можно смотреть, не выходя из Telegram.
- **Видео в шапке.** Если в статье есть ролик, он стоит в шапке поста вместо картинки
  и смотрится прямо в Telegram. Файлы .mp4 бот загружает сам (до 45 МБ), YouTube и Vimeo
  Telegram показывает своим плеером. Выключить: `VIDEO_HEADER: "0"` в `news.yml`.
- Кнопки изданий ведут на оригиналы. Если о событии пишут несколько изданий, выходит один пост.

**Дайджест в 21:00 (по Москве):** одно сообщение со всеми новостями, вышедшими с прошлого
дайджеста, по рубрикам. Каждый заголовок кликабельный и открывает полную версию новости.
Свежий дайджест бот закрепляет в канале, а прошлый открепляет. Для этого боту нужно право
администратора на изменение чужих публикаций.

## Рубрики и источники

| Рубрика | Издания |
| --- | --- |
| 🌍 Политика и мир | BBC News, The Guardian, Al Jazeera, Politico |
| 🔬 Наука и медицина | Quanta Magazine, ScienceDaily, Phys.org, ScienceAlert, Nature, Medical Xpress |
| 💻 Технологии | The Verge, Ars Technica, TechCrunch, Wired, MIT Technology Review |
| 🤖 Искусственный интеллект | The Verge AI, MIT Technology Review AI, OpenAI, Google AI + новости про ИИ из лент технологий |
| 🎮 Игры | IGN, Eurogamer, PC Gamer, Polygon, GamesIndustry.biz |
| 🎬 Кино и сериалы | Variety, Deadline, The Hollywood Reporter, IndieWire |
| ⚽ Спорт | футбол, бокс и теннис: BBC Sport, The Guardian, ESPN FC, Sky Sports |

Российских источников нет. Рубрики меняются в `feeds.py`.

## Как бот выбирает новость

1. **Очередь «созревания».** Свежая статья (не старше 12 часов) ждёт 1,5 часа: за это время
   видно, подхватили ли сюжет другие издания. Статьи без даты публикации отбрасываются.
2. **Без повторов.** Одинаковые сюжеты из разных изданий и на разных языках склеиваются
   в один (нейросеть paraphrase-multilingual-MiniLM). Перед публикацией бот сверяет новость
   со всем, что вышло за 48 часов; в спорных случаях решает Gemini.
3. **Оценка важности.** Gemini оценивает сюжет от 1 до 10, как выпускающий редактор.
   Сверху добавляются баллы за перепечатки, Google Trends и главную Hacker News.
4. **Публикация.** Выходит то, что набрало `MIN_SCORE` (сейчас 8). Рубрики идут по кругу;
   если в рубрике нет важного, слот получает следующая. Ночью и в тихие часы слоты пропускаются.

## Перевод

Заголовок, пересказ и «Что это значит?» пишет **Gemini 3.8 Flash**, полный перевод статьи
делается ей же кусками примерно по 7000 символов. Перевод проверяется на слова со смешанными
русскими и латинскими буквами («мaшина»), и такой кусок переводится заново.
Если лимит Gemini 3.8 Flash закончится, бот сам переключится на Gemini 3.5 Flash-Lite,
а если не ответит и она — на Google Translate. Английский пост не выйдет никогда:
если перевести не удалось, новость ждёт следующего запуска.

## Предупреждения в личку

Если что-то сломалось, бот пишет вам в Telegram: Gemini не отвечает или модель сняли
с поддержки, лента молчит 3 часа подряд, нет прав в канале, 8 часов без постов, упал запуск,
не вышел дайджест. Об одной и той же проблеме — не чаще раза в 6 часов.

Как включить:
1. Напишите своему боту в Telegram `/start`. Без этого бот не может писать вам первым.
2. Узнайте свой ID: откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найдите `"chat":{"id":123456789` — это число и есть ID.
3. GitHub → Settings → Secrets and variables → Actions → **New repository secret**:
   имя `ADMIN_CHAT_ID`, значение — это число.
4. Actions → **news** → **Run workflow**, в поле «Что сделать» выберите `test-alert`.
   В личку должно прийти «✅ Проверка связи».

## Где и как запускается

- **GitHub Actions** (`.github/workflows/news.yml` в корне репозитория) выполняет бота.
  Для публичного репозитория это бесплатно.
- **cron-job.org** каждые 10 минут нажимает за вас «Run workflow» через API GitHub.
  Своего расписания в `news.yml` нет специально, иначе запуски шли бы дважды.
- Память бота (что опубликовано, очередь, дайджест) хранится в кэше GitHub, а не в коммитах.

Ручной запуск: Actions → **news** → **Run workflow** → в поле «Что сделать»:
`post` — обычный пост, `digest` — дайджест прямо сейчас (вечерний не сбивается),
`test-alert` — проверка предупреждений.

### Секреты (Settings → Secrets and variables → Actions)

| Имя | Что это |
| --- | --- |
| `BOT_TOKEN` | токен бота от @BotFather |
| `CHANNEL_ID` | `@имя_канала` |
| `TELEGRAPH_TOKEN` | токен Telegraph для «Читать полностью» |
| `GEMINI_API_KEY` | бесплатный ключ с https://aistudio.google.com/apikey |
| `ADMIN_CHAT_ID` | ваш личный ID для предупреждений (необязательно) |
| `NYT_API_KEY`, `GUARDIAN_API_KEY` | топы «самое читаемое» (необязательно) |

### Что продлевать вручную

| Что | Когда |
| --- | --- |
| Токен GitHub в cron-job.org | истекает в дату, выбранную при создании. Создайте новый и вставьте в cron-job.org |
| Модель Gemini | Google снимает старые модели примерно через год. Бот предупредит; поменяйте `GEMINI_MODEL` / `GEMINI_TEXT_MODEL` |
| RSS-ленты | издания иногда меняют адреса. Бот предупредит, если лента молчит 3 часа |

## Настройка (переменные в `news.yml`)

- `MIN_SCORE` — порог публикации (8). Мало постов — уменьшите, много мелочи — увеличьте.
- `BREAKING_SCORE` — с такой оценкой новость выходит сразу, без 1,5 часа ожидания (13).
- `HOLD_MINUTES` — сколько новость «созревает» (90); `MAX_AGE_HOURS` — старше не берём (12).
- `DIGEST_HOUR` — час дайджеста (21; `-1` — выключить), `DIGEST_TZ` — часовой пояс (`Europe/Moscow`).
- `GEMINI_TEXT_MODEL` — модель для текстов (`gemini-3.8-flash`), `GEMINI_MODEL` — для оценок
  и запасная (`gemini-3.5-flash-lite`).
- `ADMIN_CHAT_ID`, `ALERT_HOURS` (6), `QUIET_HOURS` (8) — предупреждения.
- `FULL_TEXT` — `0`, чтобы не делать полный перевод в Telegraph.
- `DUP_THRESHOLD` — строгость склейки дублей (0.80): проскакивают дубли — 0.75,
  склеиваются разные новости — 0.85.

## Проверки (на своём компьютере, нужен Python)

```
pip install -r requirements.txt
python bot.py --check-feeds   # какие RSS-ленты работают
python bot.py --check-dupes   # какие свежие новости бот склеит в один пост
python bot.py --rank          # очередь с оценками, ничего не публикуя (нужен GEMINI_API_KEY)
```

## Запуск на своём сервере (Docker)

```
git clone <ваш репозиторий> news-bot && cd news-bot/telegram-news-bot
# создайте файл .env с BOT_TOKEN, CHANNEL_ID, TELEGRAPH_TOKEN, GEMINI_API_KEY, ADMIN_CHAT_ID, MIN_SCORE=8
docker compose up -d      # запуск, автоперезапуск после сбоев и перезагрузки
docker compose logs -f    # смотреть, что публикуется
```

Если бот работает на сервере, задачу в cron-job.org отключите, иначе посты пойдут дважды.
