# Новостной Telegram-канал

Каждые 10 минут бот берёт самую важную свежую новость из следующей категории
(политика → бизнес → наука → технологии → игры → кино → спорт → …), переводит её на русский
и публикует в ваш канал.

## Что умеет

- **Полное содержание.** Короткая статья (до ~3500 символов) публикуется в посте целиком.
  У длинной в посте первые абзацы, а сверху карточка с кнопкой **⚡ Instant View**:
  полный текст на русском открывается прямо в Telegram (через Telegraph).
- **Без дублей.** Одну новость пишут сразу несколько изданий, иногда на разных языках.
  Бот сравнивает их по смыслу (многоязычная нейросеть paraphrase-multilingual-MiniLM)
  и по именам и числам. В итоге выходит **один** пост с пометкой
  «🔥 Об этом пишут: Variety, Deadline, The Hollywood Reporter» и кнопками на все источники.
  Сюжеты помнятся 48 часов, поэтому то же событие не выйдет повторно ни в той же,
  ни в другой категории.
- **Важное первым.** Чем больше изданий пишет об одном событии и чем оно свежее,
  тем раньше оно попадает в канал.
- **Без мусора.** Видео, онлайн-трансляции, фотогалереи, спорт, колонки мнений
  и служебные публикации отфильтровываются (список в `feeds.py`).

## Где запускать

| | GitHub Actions | Свой сервер (VPS) + Docker |
|---|---|---|
| Цена | бесплатно (публичный репозиторий) | ~€6/мес. (например, Hetzner CX23 с IPv4, без НДС) |
| Точность расписания | запуски могут задерживаться на минуты, иногда расписание «залипает» | ровно раз в 10 минут |
| Обслуживание | ничего | раз настроить |

**Рекомендация:** начните с GitHub Actions, это бесплатно и занимает 10 минут.
Если посты начнут выходить нерегулярно, переезжайте на VPS: там тот же код,
одна команда `docker compose up -d`.

## 1. Канал и бот (5 минут)

1. Создайте канал в Telegram.
2. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите **токен** вида `123456:ABC...`.
3. Канал → Управление → Администраторы → добавьте бота с правом **«Публикация сообщений»**.
4. **ID канала**:
   - публичный канал: `@имя_канала`;
   - приватный: опубликуйте в канале любое сообщение, откройте
     `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":-100...}`.
5. **Токен Telegraph** (для Instant View): откройте
   `https://api.telegra.ph/createAccount?short_name=NewsBot&author_name=News`
   и скопируйте `access_token`.

## 2а. Запуск на GitHub (бесплатно)

1. Создайте **публичный** репозиторий. Для публичных репозиториев Actions бесплатны.
   Токены не будут видны: они хранятся в Secrets.
2. Загрузите все файлы папки, **включая скрытую папку `.github`**.
3. Settings → Secrets and variables → Actions → **New repository secret**:
   `BOT_TOKEN`, `CHANNEL_ID`, `TELEGRAPH_TOKEN`.
4. Actions → **news** → **Run workflow**. Первый запуск дольше (~2 мин), потому что скачивается
   модель для поиска дублей. Дальше она берётся из кэша.

История опубликованного хранится в кэше GitHub, а не в коммитах, поэтому репозиторий не растёт.
GitHub отключает расписание в публичных репозиториях после 60 дней без активности,
поэтому workflow каждый раз сам включает себя заново.

## 2б. Запуск на сервере (Docker)

```bash
git clone <ваш репозиторий> news-bot && cd news-bot
cp .env.example .env      # впишите токены
docker compose up -d      # запуск, автоперезапуск после сбоев и перезагрузки
docker compose logs -f    # смотреть, что публикуется
```

Нужен любой VPS от 1 ГБ RAM (Ubuntu + Docker). Если работаете на сервере,
workflow на GitHub отключите, иначе посты будут идти дважды.

## Проверки

```bash
pip install -r requirements.txt
python bot.py --check-feeds   # какие RSS-ленты работают
python bot.py --check-dupes   # какие свежие новости бот склеит в один пост
python bot.py games           # пробный пост из категории «Игры» (нужны токены в окружении)
```

## Настройка

- **Источники, категории, фильтры:** `feeds.py`. Можно добавить любой сайт с RSS.
- **Переменные окружения** (в `.env` или в workflow):
  - `TRANSLATE_TO`: язык перевода (`ru`); пусто, чтобы не переводить;
  - `FULL_TEXT`: `0`, чтобы публиковать только краткое содержание;
  - `SHORT_ARTICLE_CHARS`: статьи короче этого идут в пост целиком (3500, максимум ~3900);
  - `LEAD_CHARS`: сколько текста длинной статьи показывать в посте (1500);
  - `POSTS_PER_RUN`: постов за запуск (1);
  - `MAX_AGE_HOURS`: не публиковать новости старше N часов (24);
  - `DEDUP_HOURS`: сколько часов помнить сюжеты для отсева дублей (48);
  - `DUP_THRESHOLD`: насколько похожи должны быть новости, чтобы считаться одной (0.80).
    Если дубли проскакивают, уменьшите до 0.75. Если склеиваются разные новости, увеличьте до 0.85;
  - `INTERVAL_MIN`: интервал в режиме `--loop` (10).
